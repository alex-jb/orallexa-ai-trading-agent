## Why this change

FinPos (2025) makes an argument the Orallexa architecture currently violates: the Judge voice does two jobs simultaneously — decide the direction of the trade (long / short / no-op) AND size the position. Empirical result in FinPos: models that conflate these two decisions score worse on both directional accuracy and risk-adjusted return than models that split them into two agents.

In Orallexa terms, the current Judge voice is asked to:
1. Emit `p_up_delta` (directional signal)
2. Emit `suggested_position_usd` (size)
3. Emit `conviction` (which conflates the two)

The FinPos claim (validated on their synthetic + real Alpaca dataset) is that a specialist Risk Sizer that ONLY sees the direction, the volatility regime, the current portfolio state, and Kelly / drawdown constraints — and does NOT opine on direction — outperforms a generalist Judge on the sizing dimension by a measurable margin.

---

## Proposed architecture

### Before (current v1.1.0)

```
Bull ─┐
Bear ─┤
Judge├──── final decision (direction + size + conviction)
Critic┤
Polyseer─┘
```

The 5 voices deliberate. Judge synthesizes into one output that carries direction AND size AND conviction. Portfolio Manager gate applies risk checks post-hoc.

### After (proposed v1.2.0)

```
Bull ─┐
Bear ─┤
Judge├──── directional verdict (long / short / no-op, +confidence)
Critic┤          │
Polyseer─┘       │
                 ▼
        ┌──────────────────┐
        │  Risk Sizer voice │  ← NEW in v1.2.0
        │  Sees: direction  │
        │  + volatility     │
        │  + portfolio      │
        │  + Kelly / DD     │
        │  Refuses to opine │
        │  on direction     │
        └──────────────────┘
                 │
                 ▼
             final decision (direction from Judge + size from Sizer)
```

The Risk Sizer voice runs AFTER the debate concludes. It receives the Judge's directional verdict as INPUT (not something to challenge). Its only output is a position size, computed against:
- Current portfolio state (VaR, concentration, sector exposure)
- Volatility regime (ATR + Kronos-embedding if v1.3.0 lands)
- Kelly / fractional-Kelly with drawdown adjustment
- Explicit MAX-CAP (25% Kelly, per `engine/kelly_sizing.py`)

If the Judge says "no-op," the Sizer skips.

## Contract tests (must-write before merge)

`tests/test_risk_sizer_voice_contract.py` — pins:

1. **RS never emits a direction.** Assert `size_position(input).direction is None` for every input configuration.
2. **RS respects Kelly max-cap.** Assert `output.position_usd <= max_kelly_cap * bankroll` for all inputs.
3. **RS skips on no-op direction.** If `direction == "no_op"`, `output.verdict == "skip"`.
4. **RS scales inversely with volatility.** Assert `size_position(low_vol) > size_position(high_vol)` holding other params constant.
5. **RS respects drawdown-adjusted Kelly.** If `portfolio_state.current_drawdown_pct > 10%`, size shrinks by `drawdown_factor` (per `engine/kelly_sizing.py`).

## Integration into run_council()

`orallexa/agents/run_council.py`:

```python
# ... after existing 5-voice debate resolves ...
council_verdict = _resolve_verdict(voices)  # existing

if council_verdict.direction != "no_op":
    sizer_input = RiskSizerInput(
        direction=council_verdict.direction,
        directional_confidence=council_verdict.confidence,
        entry_price=market_state.price,
        volatility_regime=classify_volatility(market_state.atr, market_state.atr_hist),
        portfolio_state=portfolio_manager.get_state(),
        kelly_p_win=strategy_stats.p_win,
        kelly_avg_win_pct=strategy_stats.avg_win_pct,
        kelly_avg_loss_pct=strategy_stats.avg_loss_pct,
    )
    sizer_output = size_position(sizer_input)
    final = _merge_direction_with_size(council_verdict, sizer_output)
else:
    final = council_verdict  # no-op skips sizer

return final
```

The critical property: **the Judge's directional output is IMMUTABLE downstream of the Risk Sizer**. The Sizer cannot say "actually, don't take this trade" — that's the Judge's job. The Sizer can say "fund at $0" (verdict=skip), which is not the same as "don't take."

## What v1.2.0 does NOT change

- 5-voice debate (Bull/Bear/Judge/Critic/Polyseer) untouched
- Portfolio Manager gate untouched (runs BEFORE the debate, filters trade universe)
- Insider Signal, kill-conditions, ATR stops all untouched
- Brier calibration untouched
